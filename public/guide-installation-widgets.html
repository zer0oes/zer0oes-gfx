Avant de commencer

Dans ton espace commande, récupère les fichiers ou les liens d'installation du widget ou du pack d'alertes, disponibles après validation et paiement intégral. Utilise la version StreamElements ou Streamlabs correspondant à ton brief.

Si tu reçois un ZIP, extrais-le et lis son README : il précise le widget à ouvrir et les réglages à appliquer. Choisis ci-dessous la méthode correspondant à ta livraison.

Un widget est un élément connecté, pas une scène complète. Tu gardes ton jeu, ta webcam et ton habillage dans OBS ; le widget s'affiche par-dessus grâce à une source Navigateur.

ASur StreamElements

Avec un code ou un lien d'installation

  1. Dans ta livraison, clique sur Afficher mon code → Copier, puis Ouvrir c4ldas SE API. Connecte-toi avec le compte StreamElements de ta chaîne et colle le code pour importer le widget. Si un lien de partage est fourni, ouvre-le et suis ses instructions.
  2. Retrouve la création importée dans My Overlays, vérifie ses réglages et copie son URL avec Copy URL.

c4ldas SE API est le service tiers utilisé pour les codes de partage livrés. Le code sert à importer ; l'URL obtenue sert à afficher le widget dans OBS.

Avec les fichiers de code

  1. Dans My Overlays → New Overlay, crée un overlay aux dimensions recommandées dans le README. Il sert de support à ton widget.
  2. Dans l'éditeur, choisis + → Static / Custom → Custom Widget, puis ouvre l'éditeur de code.
  3. Colle le contenu de widget.html, widget.css, widget.js et fields.json dans les onglets HTML, CSS, JS et FIELDS correspondants. Ajuste les réglages fournis, enregistre, puis copie l'URL de l'overlay.
Pour un pack d'alertes livré en ZIP : utilise un widget AlertBox dans ton overlay StreamElements. Chaque dossier du pack correspond à une alerte : ouvre les réglages de l'événement ou de la variation indiqué dans le README, active Enable custom CSS → Open editor, puis colle ses fichiers dans HTML, CSS, JS et FIELDS. Répète pour chaque alerte livrée et reporte le son, le volume et la durée indiqués. Enregistre, puis copie l'URL de l'overlay contenant l'AlertBox.

BSur Streamlabs

Avec un thème prêt à installer

  1. Connecte-toi au compte Streamlabs de ta chaîne et clique sur Installer sur Streamlabs dans ta livraison.
  2. Dans Widget Themes, active le thème importé avec Use.
  3. Ouvre le widget concerné, vérifie ses réglages et copie sa Widget URL.

Avec les fichiers de code

  1. Ouvre le widget indiqué dans le README : Chat Box, Event List, un objectif ou Custom Widget, selon ta livraison.
  2. Pour un widget natif, active Custom HTML/CSS si indiqué. Pour un Custom Widget, ouvre Custom Code → Edit Custom Code.
  3. Colle les fichiers dans les champs correspondants : HTML, CSS, JS et Custom Fields lorsqu'ils sont fournis. Applique les réglages du README, enregistre et copie la Widget URL.
Pour un pack d'alertes livré en ZIP : ouvre l'Alert Box Streamlabs, puis le type d'alerte indiqué dans chaque dossier (follow, abonnement, don… selon ton pack). Active Enable Custom HTML/CSS et colle les fichiers de cette alerte dans HTML, CSS, JS et Custom Fields. Répète pour les alertes livrées, reporte le son, le volume et la durée du README, et garde le champ personnalisé « Durée de l'alerte » aligné sur la durée native lorsqu'il est fourni. Enregistre, puis copie l'URL de l'Alert Box.

Un thème configure les widgets et alertes concernés ; il n'importe pas ton habillage ni une scène OBS complète.

Ajoute ton widget dans OBS

  1. Ouvre ta scène, puis Sources → + → Navigateur. Donne un nom clair à la source, par exemple « Chat » ou « Objectif ».
  2. Colle l'URL du widget obtenue sur ta plateforme. Laisse Fichier local décoché et utilise les dimensions recommandées dans la livraison.
  3. Place le widget au-dessus des sources qui pourraient le masquer, puis ajuste sa position et verrouille-le avec le cadenas.
Garde les URLs et les codes privés. Les widgets connectés nécessitent une connexion Internet. Un fichier HTML ouvert seul ne remplace pas leur installation sur la plateforme.

Vérifie le résultat avant le live.

Envoie un message dans le chat ou vérifie les valeurs de ton objectif, selon le widget. Pour un pack d'alertes, déclenche un test de chaque événement livré depuis StreamElements ou Streamlabs et vérifie le texte, l'animation, la durée et le son dans OBS. Contrôle son affichage dans OBS avec un court enregistrement.

S'il reste vide, vérifie le compte connecté, les réglages et l'URL. Les alertes restent invisibles en dehors des événements ; certains widgets ne s'affichent qu'après un message. Vérifie aussi le niveau audio de la source Navigateur pour les alertes sonores et évite de charger la même AlertBox deux fois dans ta scène. Actualise la source Navigateur après une modification si nécessaire.
